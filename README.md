## 📁 Projects Included

### 1. Customer Churn Prediction System

**Project Overview:**

This project predicts whether a bank customer is likely to leave or continue using the bank's services. It uses customer information and a Random Forest Classifier to generate predictions.

**Algorithm:** Random Forest Classifier

**Technologies Used:**
- Python
- NumPy
- Scikit-learn
- Streamlit

**Dataset:** Churn_Modelling.csv

**Key Features:**
- Accepts customer details as input.
- Uses a trained Machine Learning model.
- Applies feature scaling to input data.
- Predicts whether the customer will stay or exit.
- Provides an interactive web interface using Streamlit.

**How to Run:**

```bash
pip install streamlit numpy scikit-learn
streamlit run app.py
```

**Expected Output:**
- Customer Will Stay
- Customer Will Exit

## 📌 Installation

Install the commonly used Python libraries:

```bash
pip install numpy pandas matplotlib seaborn scikit-learn jupyter
```

For projects using Streamlit:

```bash
pip install streamlit
```

Alternatively, install the dependencies listed in `requirements.txt`:

```bash
pip install -r requirements.txt
```
